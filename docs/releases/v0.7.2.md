Draft notes for the release after 0.7.1. The version number is not decided yet.

## Fixed

- Black and white blocks on AMD RX 5000 and RX 6000 cards: on Navi and on Link next to her, on bright floors near her,
  and on the bright outdoors seen through a door or window from inside a house. Every float colour a shader writes is
  checked for NaN, so that one bad pixel cannot spread through the blur and bloom passes; those checks, and the
  game's own NaN tests in nearly nine of ten shaders, are float comparisons that a shader compiler may decide can
  never be true. The Windows driver for these cards uses AMD's older shader compiler (the log reads "AMD proprietary
  shader compiler"); with it each NaN test is now made on the bits of the number instead, which no compiler can drop.
  It is on by default only with that driver (`vk_nan_bits`); the first start after the update compiles the pipelines
  again. Untested on those cards before this release: please report whether the blocks are gone.
